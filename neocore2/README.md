# NewEngine (Workspace)

Этот репозиторий — модульный игровой движок на Rust, ориентированный на **детерминизм**, **плагинную архитектуру** и *
*AAA-ready пайплайн**.

## Быстрый старт

```bash
cargo build
cargo run -p editor
```

## Документация

- `ARCHITECTURE.md` — слои и правила зависимостей
- `crates/*/README.md` — назначение и инварианты каждого крейта
