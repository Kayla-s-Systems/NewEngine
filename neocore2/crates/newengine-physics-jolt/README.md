# newengine-physics-jolt

    Физический бэкенд Jolt: мир физики и мост к ECS/сцене.

    ## Роль в архитектуре

    - **Слой:** `crates/newengine-physics-jolt`
    - **Назначение:** Физический бэкенд Jolt: мир физики и мост к ECS/сцене.

    ## Инварианты

    - Физика шагает в fixed_update и пишет результаты детерминированно.

- Интеграция — через явные компоненты/ресурсы, без скрытого доступа.

  ## Публичный API

    - Смотри `src/lib.rs` и модульные реэкспорты.
    - Для контрактов/ABI: фиксируйте изменения через версионирование (semver) и миграции.

  ## Тестирование и профилирование

    - Unit-тесты: `cargo test -p newengine-physics-jolt`
    - (Рекомендуется) bench/criterion для hot path.
