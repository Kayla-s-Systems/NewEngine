# newengine-camera

    Камера: rigs, контроллеры, модификаторы, проекции. Чистая математика, без привязки к платформе.

    ## Роль в архитектуре

    - **Слой:** `crates/newengine-camera`
    - **Назначение:** Камера: rigs, контроллеры, модификаторы, проекции. Чистая математика, без привязки к платформе.

    ## Инварианты

    - Камера должна быть pure, детерминированной и тестируемой.

- Интеграция с ECS — через компоненты в newengine-sim или через отдельный модуль.

  ## Публичный API

    - Смотри `src/lib.rs` и модульные реэкспорты.
    - Для контрактов/ABI: фиксируйте изменения через версионирование (semver) и миграции.

  ## Тестирование и профилирование

    - Unit-тесты: `cargo test -p newengine-camera`
    - (Рекомендуется) bench/criterion для hot path.
