# newengine-camera

Камера как чистый домен: rigs, проекции, контроллеры и детерминированные модификаторы.

## Ответственность

- Геометрия камеры: проекции, frustum.
- Camera rigs и состояние.
- Контроллеры и модификаторы, пригодные для gameplay и editor.

## Не ответственность

- Не зависит от платформы (winit), UI и render backend’а.
- ECS-интеграция делается верхним слоем (`newengine-camera-runtime` / `newengine-sim`).

## Инварианты

- Pure и тестируемость: никакого скрытого IO.
- Детерминированное поведение при одинаковом вводе.
