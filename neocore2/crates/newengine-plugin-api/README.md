# newengine-plugin-api

    Чистый ABI-контракт для внешних плагинов (DLL). Без зависимостей на реализации конкретных модулей.

    ## Роль в архитектуре

    - **Слой:** `crates/newengine-plugin-api`
    - **Назначение:** Чистый ABI-контракт для внешних плагинов (DLL). Без зависимостей на реализации конкретных модулей.

    ## Инварианты

    - ABI должен быть стабильным и минимальным: только договорённости, версии, capability-описания, точки входа.

- Никаких типов/enum конкретных плагинов — их описывает сам плагин через capabilities.

  ## Публичный API

    - Смотри `src/lib.rs` и модульные реэкспорты.
    - Для контрактов/ABI: фиксируйте изменения через версионирование (semver) и миграции.

  ## Тестирование и профилирование

    - Unit-тесты: `cargo test -p newengine-plugin-api`
    - (Рекомендуется) bench/criterion для hot path.
