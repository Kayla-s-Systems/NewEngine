# newengine-editor-core

Базовые **доменные типы редактора**: состояние редактора, выделение (selection), команды редактирования и
детерминированный undo/redo.

## Ответственность

- `SelectionModel` — детерминированная модель выделения (стабильный порядок по `EntityId::stable_u64()`).
- `EditorCommand` и `CommandStack` — операции редактирования, пригодные для undo/redo.
- `EditorState` — единый контейнер для selection/tool/gizmo/undo.

## Не ответственность

- Не рисует UI и не зависит от egui.
- Не содержит логики Scene/Transform (это домены `newengine-scene` и `newengine-transform`).
- Не владеет сохранением/загрузкой ассетов.

## Инварианты

- Любая итерация выделения должна быть детерминированной.
- Команды редактирования должны быть сериализуемыми/воспроизводимыми (в перспективе: command log).
