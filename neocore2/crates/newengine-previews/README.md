# newengine-previews

Сервис предпросмотров для редактора: рендер маленьких offscreen-картинок (preview RT) для списков/инспектора/браузера
ассетов.

## Ответственность

- `PrimitivePreviewService` — генерация превью примитивов/встроенных объектов.
- Стабильные ключи превью и кеширование, чтобы UI не дёргал GPU лишний раз.
- Интерфейс выдачи `UiTexId`/handle для UI слоя.

## Не ответственность

- Не является полноценным рендерером сцены.
- Не занимается импортом ассетов (это `newengine-assets` + импортёр плагины).
- Не хранит Scene/ECS; принимает только необходимые данные.

## Инварианты

- Превью должны быть детерминированны при одинаковых входных параметрах.
- Сервис не должен блокировать кадр: все ожидания — через pump/poll.
