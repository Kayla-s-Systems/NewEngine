# newengine-core

    Ядро NewEngine: оркестрация модулей, жизненный цикл плагинов, Host API, события/сервисы, рендер-абстракции и инварианты.

    ## Роль в архитектуре

    - **Слой:** `crates/newengine-core`
    - **Назначение:** Ядро NewEngine: оркестрация модулей, жизненный цикл плагинов, Host API, события/сервисы, рендер-абстракции и инварианты.

    ## Инварианты

    - Ядро не знает типов конкретных плагинов; все доменные типы живут в плагинах/модулях.

- Все взаимодействия модулей — через явные сервисы/события, без скрытого доступа к чужим данным.
- Детерминизм: упорядоченные стадии/вызовы, отсутствие скрытого async в ядре.

  ## Публичный API

    - Смотри `src/lib.rs` и модульные реэкспорты.
    - Для контрактов/ABI: фиксируйте изменения через версионирование (semver) и миграции.

  ## Тестирование и профилирование

    - Unit-тесты: `cargo test -p newengine-core`
    - (Рекомендуется) bench/criterion для hot path.
