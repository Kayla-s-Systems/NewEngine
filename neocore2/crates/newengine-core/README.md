# newengine-core

Хост NewEngine: оркестрация модулей, загрузка плагинов, сервисы/события, ошибки и render-абстракции.

## Ответственность

- Жизненный цикл `Engine` и модулей (`Module`, `ModuleCtx`, stages).
- Загрузка плагинов и Host API.
- `ServiceRegistry` + типы `ErasedService`, `MissingServicePolicy`.
- `EventHub` и подписки.
- Абстракция `RenderApi` (контракт), без привязки к конкретному backend’у.
- Стартовая конфигурация (`StartupLoader`).

## Не ответственность

- Не знает типов конкретных плагинов и их доменных enum’ов.
- Не содержит gameplay/scene/transform логики.

## Инварианты

- Все взаимодействия доменов должны происходить через явные сервисы/события/контракты.
- Любая доменная интеграция должна быть расширяемой (capabilities), без хардкода в ядре.
