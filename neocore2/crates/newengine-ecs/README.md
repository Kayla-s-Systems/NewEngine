# newengine-ecs

    Детерминированный ECS: сущности с генерациями, компонентные хранилища, запросы и командный буфер.

    ## Роль в архитектуре

    - **Слой:** `crates/newengine-ecs`
    - **Назначение:** Детерминированный ECS: сущности с генерациями, компонентные хранилища, запросы и командный буфер.

    ## Инварианты

    - EntityId — generational key; нельзя хранить его как persistent id для сцен/ассетов.

- Все структурные изменения — через Commands (двухфазный коммит).
- Change tracking: added/changed ticks.

  ## Публичный API

    - Смотри `src/lib.rs` и модульные реэкспорты.
    - Для контрактов/ABI: фиксируйте изменения через версионирование (semver) и миграции.

  ## Тестирование и профилирование

    - Unit-тесты: `cargo test -p newengine-ecs`
    - (Рекомендуется) bench/criterion для hot path.
