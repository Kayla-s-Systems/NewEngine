# newengine-audio-api

    Audio API (контракт/протокол): идентификаторы, wire-типизация, capabilities и модели аудио-систем.

    ## Роль в архитектуре

    - **Слой:** `crates/newengine-audio-api`
    - **Назначение:** Audio API (контракт/протокол): идентификаторы, wire-типизация, capabilities и модели аудио-систем.

    ## Инварианты

    - Это API/контракт: реализации — в аудио-модулях/плагинах.

- Версионирование протокола обязательно.

  ## Публичный API

    - Смотри `src/lib.rs` и модульные реэкспорты.
    - Для контрактов/ABI: фиксируйте изменения через версионирование (semver) и миграции.

  ## Тестирование и профилирование

    - Unit-тесты: `cargo test -p newengine-audio-api`
    - (Рекомендуется) bench/criterion для hot path.
