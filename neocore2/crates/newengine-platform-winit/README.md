# newengine-platform-winit

Платформенный хост (winit): окно, цикл событий, мосты ввода, интеграция UI.

## Роль в архитектуре

- **Слой:** `crates/newengine-platform-winit`
- **Назначение:** Платформенный хост (winit): окно, цикл событий, мосты ввода, интеграция UI.

## Инварианты

- Хост не содержит gameplay: только платформа, тайминг, ввод, запуск ядра.

## Публичный API

- Смотри `src/lib.rs` и модульные реэкспорты.
- Для контрактов/ABI: фиксируйте изменения через версионирование (semver) и миграции.

## Тестирование и профилирование

- Unit-тесты: `cargo test -p newengine-platform-winit`
- (Рекомендуется) bench/criterion для hot path.
