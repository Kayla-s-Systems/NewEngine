# KΛYLΛ FPS: Extraction Yard

Minimal playable first-person vertical slice built on the existing NewEngine editor runtime.

Run from the workspace root:

```bash
cargo run -p game-ready-fps
```

Controls:

- `WASD` — move
- Mouse — look
- `Shift` — sprint
- `ESC` — return to editor mode

Goal:

Collect the 3 blue cores, avoid purple hazard zones, then reach the red extraction beacon.
